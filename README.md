# Python Day 128 - Common Elements in Two Lists

This Python program finds elements that are present in both lists.

## Example

First list:
```text
[10, 20, 30, 40, 50]
```

Second list:
```text
[30, 40, 50, 60, 70]
```

Output:
```text
Common elements: [30, 40, 50]
```

## Concepts Used

- Python lists
- `for` loop
- `if` statement
- `in` operator
- `append()` method

## How It Works

The program checks each element in the first list. If the element is also present in the second list, it is added to the `common` list.

## What I Learned

I learned how to find common elements between two lists using a loop and the `in` operator.
